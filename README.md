# NEBIUS_TRACKER

NEBIUS_TRACKER er en liten dashboard-løsning for NBIS-data med:

- en statisk frontend som kan publiseres på GitHub Pages
- en FastAPI-backend som leverer kursdata og hendelser
- enkel lokal utvikling uten Node-byggesteg

Installasjon, konfigurasjon, lokale kommandoer og GitHub Pages-oppsett er beskrevet i [docs/installasjon-og-konfigurasjon.md](docs/installasjon-og-konfigurasjon.md).
